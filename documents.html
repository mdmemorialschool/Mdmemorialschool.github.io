Required Documents

Documents required for admission

🪪

Student Aadhaar Card

Student's Aadhaar Card is required.

📜

Birth Certificate

Required only if Aadhaar Card is unavailable.

🔢

PEN Number

Student's PEN number is required.

📄

Previous School Report Card / Marksheet

Required for students coming from another school.

📑

Transfer Certificate

Required if applicable.

📸

Passport Size Photographs

Recent passport size photographs of the student.

🪪

Parent / Guardian Aadhaar

Aadhaar Card of parent or guardian is required.

🏠

Address Proof

Valid address proof of the parent or guardian.

📱

WhatsApp Mobile Number

Active WhatsApp number of the parent or guardian.

Important Note

Please keep all required documents ready before completing the admission process. Documents should be clear and valid.
